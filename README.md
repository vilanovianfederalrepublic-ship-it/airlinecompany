# Airline Company v0.7.1

Airline Company is a standalone HTML5 airline-management simulation built with HTML, CSS and vanilla JavaScript. Open `Airline_Company_v0.7.1.html` in a modern browser. No installation or account is required.

## v0.7.1 highlights

- Persistent app-style navigation: desktop sidebar and mobile/tablet bottom navigation.
- Home dashboard and separate screens for routes, schedules, fleet, airport, headquarters, research, competition, achievements and finances.
- Company headquarters expansion with five upgrade levels.
- Airport terminal development: boarding gates, premium lounges, baggage systems and check-in counters.
- Per-route departure frequency settings (30 seconds, 60 seconds, 2 minutes or 4 minutes).
- Research tree with operational efficiency, demand analytics, weather forecasting, cabin innovation and route optimization.
- Aircraft livery colors and aircraft naming.
- Competitor intelligence with a live airline ranking.
- Additional achievements with cash rewards.
- Research and terminal upgrades affect demand, costs, weather performance and turnaround times.

## Existing features retained

Aircraft purchasing and leasing, aircraft condition and maintenance, route planning, ticket fares, cabin service, airport upgrades, company investments, cargo contracts, alliances, loans, weather events, rival airlines, passenger satisfaction, route map, save/load, export/import and achievements.

## Saves

Progress is stored in browser localStorage on the current device. Use **Finances → Export save** to back up progress and **Import save** to restore it. v0.7.1 migrates supported v0.7 and earlier save structures when they are loaded. Export a backup before updating as a precaution.

## Notes

This is a fictional management simulation. Departure frequency is measured in accelerated in-game seconds, not real-world clock time. The file is self-contained and does not require an internet connection.
