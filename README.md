Airline Company v0.6

Airline Company is a standalone HTML5 airline management game built with HTML, CSS and JavaScript.

Build your own airline, purchase aircraft, establish routes, manage ticket prices, improve airports and grow your aviation business.

Features

Build and manage your airline.

Purchase and maintain aircraft.

Establish multiple flight routes.

Set ticket prices and service levels.

Upgrade airports.

Manage finances and reputation.

Automatic flights and random events.

Save and load your progress.

Export and import save files.

Responsive interface for desktop and mobile.

How to play

Open index.html in a modern web browser.

Save data

The game uses browser localStorage for saving progress. Saves are stored locally in the browser and are not automatically synchronized between devices.

Use the in-game export and import options to back up and restore progress.
