Airline Company v0.7

Airline Company is a standalone HTML5 airline management game built with HTML, CSS and vanilla JavaScript.

Build an airline from a single aircraft into an international network. Purchase or lease aircraft, open routes, set fares and service standards, maintain your fleet, compete with rival airlines, and manage finances.

Version 0.7 features

- Expanded airport database, including Athens, Warsaw, Copenhagen, Lisbon, Hong Kong, San Francisco, Bangkok, Johannesburg, Reykjavik and Munich.
- Additional aircraft available for purchase.
- Airline competitors that influence passenger demand.
- Dynamic weather, including rain, storms and strong winds that affect operations.
- Passenger satisfaction and reputation effects.
- Flight numbers and aircraft naming.
- Aircraft condition, maintenance and repair.
- Aircraft leasing with per-flight lease fees.
- Cargo contracts, staff recruitment and airline alliance membership.
- Difficulty settings and emergency credit with automatic repayment.
- Achievement tracking with unlock rewards.
- Schematic route network map.
- Responsive layouts and touch-friendly controls for phones, tablets and desktops.
- Scroll-position preservation and reduced full-page redraws during simulation ticks.
- Fixed duplicate autosave timers.
- Save migration: existing v0.6-era saves are upgraded when loaded.

How to play

Open index.html in a modern web browser. Start a new airline or continue a saved game. Use the tabs to manage routes, aircraft, airport development, finances, world conditions and achievements.

Save data

The game uses browser localStorage. Saves remain in the current browser on the current device and are not automatically synchronized between devices. Use Export save and Import save to transfer a backup. Existing version 5 saves are migrated to the v0.7 save structure when loaded.
